# Pitch deck content (10 slides, Figma template "QOSTANAI" recolored to Freedom green)

Numbers below are measured on the DEV set on 2026-11-07 with Claude Opus 5.5, prompt v1; update after the gold-set calibration and the control run.

## 01 Title
**CQA by Freedom** — оценка качества диалогов, которой можно доверять.
Chips: QA-аналитик · Проверяющий · Руководитель · Dynamics 365-ready.

## 02 Problem
- 8 000 обращений и 9 000 звонков в месяц; вручную прослушивается малая доля.
- Чек-лист живёт в документах, оценки субъективны, апелляции в переписке.
- Нужна система, которая оценивает каждый диалог по действующему чек-листу, объясняет каждый балл репликой и позволяет оспорить и исправить.

## 03 Roles
- QA-аналитик: импортирует диалоги, запускает оценку, читает объяснения, подаёт апелляции.
- Проверяющий: видит спорный критерий, комментарий и фрагмент, подтверждает или меняет оценку с причиной; итог пересчитывается.
- Руководитель: аналитика по операторам, языкам, каналам; согласованность ИИ и проверяющих; стоимость.

## 04 Flow
import → normalize → judge (8 критериев, по одному вызову) → validate evidence → score (детерминированно) → review → learn (решения проверяющего становятся примерами для судьи).
Checklist is a product: версии, диф, частичная переоценка только изменённых критериев.

## 05 Measured
- 65 диалогов DEV (RU/KZ/EN чаты + 5 звонков) оценены за 5,5 минут, 0 сбоев.
- $0,20 и 20 с на чат; $0,30 на звонок; полный прогон $14.
- 8 грубых нарушений найдены, ложных срабатываний 0 (сверка с ручным разбором).
- Согласованность с ручным разбором по C1/C3/C7/C8: 4 спорных случая из 65 диалогов.
- (после калибровки) согласие с золотым набором по критериям: …; MAE итога: …

## 06 AI modules
- Judge: транскрипт сначала, скомпилированная процедура решения потом; структурированный JSON; цитаты проверяются по транскрипту; жёсткие правила N/A из чек-листа.
- Ensemble: Opus ×2 + Sonnet голосуют, арбитр при расхождении; локальная модель (vLLM на кластере) как третий голос и вариант on-prem.
- Audio: запись из плеера организаторов, темп, паузы, удержания, доля речи → критерий 6.
- Claims ledger: утверждения оператора сверяются с фактами компании (меню, сроки, комиссии).

## 07 Analytics
Распределение итогов, тепловая карта критериев по языкам и каналам, рейтинг операторов, худшие диалоги, согласие ИИ и проверяющих (каппа), стоимость и задержка по провайдерам, доля первых ответов дольше 3 минут.

## 08 Architecture and security
FastAPI + SQLite/Postgres · React static bundle (один HTML-файл для Dynamics 365, embed-режим карточки) · Claude API / локальная модель через OpenAI-совместимый endpoint · маскирование PII перед облаком · полный trace каждого вызова (модель, версия промпта, токены, стоимость) · Docker compose и hosted-версия.

## 09 Effect and adoption
- 100% покрытие диалогов вместо выборки; минуты вместо дней.
- Стоимость оценки 1 диалога ≈ 100 ₸ в облаке, 0 ₸ на локальной модели.
- Внедрение: web-ресурс в Dynamics 365 Customer Service, адаптер к msdyn_transcript, тот же чек-лист для чатов и звонков.
- Дальше: авто-коучинг операторов, тренды, A/B чек-листов.
